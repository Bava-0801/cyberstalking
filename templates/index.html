Security & Detection Capabilities

Structured cyber safety tooling engineered for proactive harassment risk assessment and evidence preservation.

AI Message Analysis

Natural language processing utilizing TF-IDF vectorization and classification to detect patterns associated with digital harassment and coercive messaging.

Behavioural Detection

Rule-based behavioural analysis across six threat dimensions: location monitoring, physical surveillance, repeated unwanted contact, intimidation, and pressure tactics.

Risk Scoring

Deterministic, weighted scoring combining model probability distributions with behavioral markers to generate calibrated Low, Medium, and High threat classifications.

Potential Identity Indicators

Systematic inspection of sender metadata, handle anomalies, and missing profile references to surface potentially deceptive or unverified sender indicators.

Evidence Management

Secure screenshot and document archiving backed by automatic SHA-256 cryptographic hashing to maintain immutable file integrity references.

Secure Authentication

PBKDF2/scrypt cryptographic password hashing, role-based access control, session-bound cookies, and an auditable security event log.

Incident Analysis Workflow

From submission to structured risk report in five straightforward steps.

STEP 01

Submit Communication

Input platform, sender metadata, message body, and optional screenshot/PDF evidence.

STEP 02

AI Model Inference

TraceX vectorizes text content and computes multi-class harassment probabilities.

STEP 03

Behavioural Detection

Rule engines screen for surveillance language, location monitoring, and intimidation.

STEP 04

Risk Scoring

Weighted algorithms synthesize model confidence and behavior into a 0–100 risk rating.

STEP 05

Secure Archiving

Incident details, SHA-256 evidence hash, and audit logs are recorded in SQLite.

Security & Integrity Controls

Ground-truth security controls actively enforced across the application stack.

Security Layer Implementation Mechanism Status
Credential Storage Werkzeug PBKDF2/scrypt one-way password hashing (salt + iterations) Active

Evidence Hashing SHA-256 cryptographic verification upon upload Active
Database Queries Strict parameterized SQL queries preventing injection attacks Active
